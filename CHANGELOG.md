## 1.0.0 - 2026-08-10

First stable release of iOS Location Spoofer Plus.

### Added

- One-stop Cloudflare Worker / Pages dashboard with KV-backed TOKEN and location management.
- Generated configurations for Shadowrocket, Surge, Loon, Quantumult X, and Stash.
- Built-in OSM, Carto, Esri, OpenTopo, Amap vector, and Amap satellite map layers.
- Complete Chinese and English deployment, setup, migration, and troubleshooting guides.

### Stabilized

- The official dynamic module intercepts only Apple WLOC responses.
- HTTPS MITM hostnames are injected by the module; no manual host list is required.
- Full binary response handling uses `max-size=0` and a 30-second script timeout.
- Legacy Apple Park and static diagnostic modules now return `410 Gone` to prevent module conflicts.
- Standard installation requires no custom proxy, DNS, Fake-IP, or CNAME rule.
